# Wazuh SIEM Configuration

Configuration files and deployment guides for Wazuh agent-based SIEM monitoring.

## Components

- `agent-deployment.sh` - Automated agent deployment script
- `ossec.conf` - Agent configuration (sanitized)
- Custom decoders and rules for enhanced detection

## Deployment Overview

1. Wazuh Manager (central server)
2. Wazuh Agents (monitored endpoints)
3. Elasticsearch integration for log storage
4. Kibana dashboard for visualization

## Features Implemented

- Multi-agent monitoring
- Real-time threat correlation
- Asset inventory tracking
- MITRE ATT&CK integration
- Automated alerting
